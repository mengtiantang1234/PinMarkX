### ✨ 核心功能亮点一览

- 🎯 **精准选区与窗口吸附**：控件级自动探测，多图层吸附，内置智能防重叠长截图算法。
- 📌 **快捷贴图置顶 (`F3`)**：一键将截图钉在桌面最前端，支持自由缩放、透明度调节与穿透比对。
- 🌐 **九国语言全离线 OCR (`O`)**：内置中/英/日/韩/德/西/法/俄离线模型，100% 保护隐私。同语种直接复制，跨语种智能翻译 (`F`)。
- 🔍 **屏幕拾色器与放大镜 (`Alt + C`)**：16×16 像素级高精度放大，一键复制 HEX / RGB 代码。
- 🎥 **高清屏幕录像机 (`Alt + R`)**：全屏/区域高清录制，内置悬浮胶囊控制条。
